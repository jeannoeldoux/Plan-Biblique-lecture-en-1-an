Sauvegarder et récupérer mon suivi

Vos coches, notes et réglages restent enregistrés dans le navigateur utilisé. Les mises à jour de l’application et le retrait d’un téléchargement hors connexion ne les effacent pas. Une suppression des données du navigateur, un changement d’adresse du site ou un nouvel appareil nécessitent une sauvegarde.

Créer une copie protégée

  1. Ouvrez votre plan et votre version de Bible.
  2. Appuyez sur « Sauvegarder », puis choisissez et confirmez une phrase secrète d’au moins 12 caractères.
  3. Conservez le fichier JSON téléchargé et son mot de passe séparément, en lieu sûr.
  4. Pour vérifier le fichier, utilisez « Contrôler une sauvegarde » dans les outils de suivi.

Le chiffrement protège le fichier exporté. Les notes conservées dans le navigateur restent accessibles à une personne ayant accès à votre appareil. Aucun mot de passe n’est enregistré : un mot de passe perdu ne peut pas être réinitialisé.

Retrouver le suivi

  1. Sur le nouvel appareil, choisissez le même plan et la même version de Bible.
  2. Dans « Outils et réglages », ouvrez « Mon suivi, mes notes et mes sauvegardes » et importez votre fichier.
  3. Saisissez son mot de passe s’il est protégé.
  4. Vérifiez le résumé et les choix de fusion, notamment les notes différentes, puis confirmez l’import.

Les anciens fichiers sans mot de passe restent compatibles. La copie automatique avant import et les autres exports classiques sont sans mot de passe ; utilisez d’abord « Sauvegarder » pour créer une copie protégée. Chaque plan et version conserve un suivi distinct : sauvegardez séparément ceux que vous utilisez.

Plusieurs appareils

Transférez manuellement ce fichier protégé entre vos appareils. Il n’y a pas de synchronisation automatique ni de compte utilisateur ajouté par cette fonction.

Vérifier le fichier téléchargé

Après un export, le bouton « Vérifier le fichier que je viens de télécharger » ouvre le contrôle existant. Choisissez le fichier réellement enregistré, puis son mot de passe s’il est protégé. Le contrôle vérifie sa compatibilité et compare les éléments du suivi, sans importer ni modifier vos données.

Le rythme personnel et le dernier repère écrit sont inclus dans les nouvelles sauvegardes. À l’import, cochez leur option uniquement si vous souhaitez remplacer ces réglages sur l’appareil de destination. Les anciennes sauvegardes restent compatibles.
