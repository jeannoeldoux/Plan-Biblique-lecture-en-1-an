# Contrôle de la version 2026.10.06.40

Menu partagé présent sur les 59 pages. Les essais confirment : lien du parcours sélectionné et de sa version ; accès aux outils des plans annuels et des parcours d’étude ; accès aux mises à jour avec focus sur le bouton ; ouverture au clavier et fermeture par Échap avec retour du focus ; invitation d’installation visible sur l’accueil, reportée sept jours et toujours disponible dans le menu ; gestion d’une invitation native annulée ; masquage lors de l’événement appinstalled ou en mode standalone simulé ; menu et instructions disponibles hors ligne ; quatre largeurs pour le menu et les instructions ouverts ; aucune erreur JavaScript.

La détection du rappel de sauvegarde a aussi été corrigée pour utiliser les véritables clés des notes et des journées cochées. Un suivi constitué seulement de notes ou seulement de journées cochées déclenche correctement le rappel, sans modifier ce suivi.

Les contrôles de mise en page des 59 pages à six largeurs (354 contrôles) passent. Les nouveaux liens et contenus d’installation ont aussi été testés à quatre largeurs. Les 36 jeux de lectures et de commentaires sont identiques à la version 39. La migration réelle de l’archive 34 vers cette version conserve chaque entrée de stockage local à l’identique. Les filtres de recherche, l’accueil, les exports, leur annulation, leurs dates, les rappels et le mode hors ligne sont vérifiés à nouveau.

L’installation native a été simulée pour vérifier les états de l’interface ; il ne s’agit pas d’un essai physique sur iPhone ou Android. Pour l’installation réelle, publier tous les fichiers puis ouvrir le site HTTPS dans Safari ou Chrome. Les instructions s’appuient sur les aides officielles : https://support.apple.com/fr-fr/guide/iphone/iphea86e5236/ios et https://support.google.com/chrome/answer/9658361?hl=fr&co=GENIE.Platform%3DAndroid

Aucune publication GitHub n’a été effectuée. Les données de test sont fictives et isolées des données du lecteur.
